# Snake Game

A simple implementation of the classic Snake game where the player navigates a snake to eat pink orbs and achieve a high score.

## How to Play

* **Controls:** Use the **W**, **A**, **S**, **D** keys to turn the snake's direction.
* **Objective:** Guide the snake to eat the **Pink Orb**.
* **Scoring:** Every orb eaten grows the snake's tail and awards **10 points**.
* **Game Over:** Hitting the wall or the snake's own tail will result in failure and automatically **restart** the game with the player's personal high score displaying on the top left.
